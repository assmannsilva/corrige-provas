# Tailwind CSS Development

Reuse existing Vue UI primitives in `resources/js/components/ui`. Compose consistent responsive layouts using Tailwind utility classes, good focus states and accessible labels. Prefer existing dialog, button and input primitives to bespoke markup. The identification dialog must support a required student name, optional class, processing state, validation messages and keyboard navigation. Keep camera controls usable on mobile, and review layouts for both narrow and wide screens.
