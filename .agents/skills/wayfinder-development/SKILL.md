# Wayfinder Development

Use typed route functions generated by Wayfinder when calling Laravel endpoints from Vue/Inertia. Controllers and route names defined in `routes/web.php` are the source of truth. Use `resources/js/routes` generated at build time where applicable. Update frontend imports, navigation and tests whenever a route signature changes. Do not hardcode external AI endpoints or expose backend credentials to the client. Run the project's normal build generation steps before validating TypeScript if Wayfinder outputs are absent from the source tree.
